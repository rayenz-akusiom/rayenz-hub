Rayenz Hub

Local development

Status refreshes every 2s. API start runs sam build first and can take a minute. One-time: npm run init:local-db and create MinIO bucket rayenz-hub-data-local. Vite and SAM bind on the LAN by default.

Device access (LAN)

Same Wi‑Fi as this PC. Windows Firewall may need inbound TCP 5173 and 3000. Open Hub Web on the phone, then Settings → Hub API → Sign in. Vite points the API at this PC's LAN IP automatically.
